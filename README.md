# 🚀 Amazing Sign-Up Form

A modern and dark-themed Sign-Up form built during my early CSS & JavaScript learning journey, focusing on core positioning, custom styling, and practical DOM manipulation.

🔗 **Live Demo:** [View Demo](https://simo-g1.github.io/amazing-sign-up-form)  

## ✨ Features
* **Modern Dark UI:** Clean design inspired by developer platforms like GitHub[cite: 6, 7].
* **Password Visibility Toggle:** Interactive show/hide password feature powered by Vanilla JavaScript[cite: 6].
* **Password Validation:** Client-side JavaScript check to ensure matching passwords before form submission[cite: 6].
* **Smooth CSS Transitions:** Micro-interactions and hover effects on form inputs and buttons[cite: 6].
* **Google Fonts Integration:** Styled using custom typography (`Playwrite AU TAS`)[cite: 6, 7].

## 🛠️ Technologies Used
* **HTML5:** Semantic form structure, input attributes, and layout markup[cite: 6].
* **CSS3:** Absolute positioning, custom variables, box-shadows, and smooth transitions[cite: 6, 7].
* **JavaScript (Vanilla):** Event listeners, DOM manipulation, and dynamic field validation[cite: 6].
