# 🚀 Amazing Sign-Up Form

A modern and dark-themed Sign-Up form built during my early CSS & JavaScript learning journey, focusing on core positioning, custom styling, and practical DOM manipulation.

🔗 **Live Demo:** [View Demo](https://simo-g1.github.io/amazing-sign-up-form)  

## ✨ Features
* **Modern Dark UI:** Clean design inspired by developer platforms like GitHub.
* **Password Visibility Toggle:** Interactive show/hide password feature powered by Vanilla JavaScript].
* **Password Validation:** Client-side JavaScript check to ensure matching passwords before form submission.
* **Smooth CSS Transitions:** Micro-interactions and hover effects on form inputs and buttons.
* **Google Fonts Integration:** Styled using custom typography.

## 🛠️ Technologies Used
* **HTML5:** Semantic form structure, input attributes, and layout markup.
* **CSS3:** Absolute positioning, custom variables, box-shadows, and smooth transitions.
* **JavaScript (Vanilla):** Event listeners, DOM manipulation, and dynamic field validation.
